# Open Abbrev

**Open Abbrev**는 짧은 글쇠 조합으로 단어나 문장을 빠르게 입력할 수 있는 Windows용 오픈소스 약어(Open-source Abbreviation) 프로그램입니다. **이어치기**와 **모아치기**를 지원하며, 자판에 맞는 약어 목록을 직접 바꿀 수 있습니다.

영어 약어 사전은 **COCA(Corpus of Contemporary American English)**의 단어 빈도 자료를, 한국어 약어 사전은 **국립국어원의 단어 빈도 통계**를 참고하여 구성하였습니다.

이 프로젝트는 현재 AutoHotkey 프로토타입으로 **Alpha** 단계에 있습니다.
(AutoHotkey 코드는 AI의 도움으로 작성되었습니다.)

---

# Ⅰ. 사용자 안내서

## 1. 설치하고 실행하기

Windows와 [AutoHotkey v2](https://www.autohotkey.com/)가 필요합니다.

1. AutoHotkey v2를 설치합니다.
2. Open Abbrev를 내려받아 압축을 풉니다.
3. `open-abbrev.ahk` 파일을 메모장으로 열고, 맨 위의 `DictionaryDir`에서 사용할 약어 폴더를 선택합니다.
(`open-abbrev.ahk`와 `english` 등의 언어 폴더는 같은 폴더에 두십시오.)
4. 파일을 저장한 뒤 `open-abbrev.ahk`를 실행합니다.

예를 들어 **Windows 입력기 + 영문 QWERTY**를 사용한다면 다음과 같이 설정합니다.

```ahk
global DictionaryDir := A_ScriptDir "\english\windows-ime\qwerty"
```

날개셋 입력기의 Colemak을 사용한다면 다음과 같이 설정합니다.

```ahk
global DictionaryDir := A_ScriptDir "\english\nalgaeset-ime\colemak"
```

해당 폴더에 약어 목록이 없다면 다른 폴더의 파일을 복사한 다음 수정할 수 있습니다.


- **안티바이러스 오탐지 안내:** 이 프로그램은 키보드 입력을 가로채고 다시 입력하는 방식으로 동작하므로 일부 백신 프로그램의 행동 기반 탐지 메커니즘에서 오탐지될 수 있습니다. 따라서 사용 중인 백신 프로그램에서 예외 목록에 추가하는 것을 권장합니다.

## 2. 약어 사용하기

| 방식 | 사용 방법 | 예시 |
|---|---|---|
| **이어치기** | 정해진 글자를 순서대로 입력한 다음 공백이나 문장부호 등을 누릅니다. | `func` 입력 후 공백 → `function` |
| **모아치기** | 정해진 글쇠를 거의 동시에 누릅니다. 순서는 상관없습니다. | `the` 글쇠를 한 번에 누름 |

이어치기는 약어를 입력하는 즉시 바뀌지 않고, **공백이나 약어를 끝내는 글쇠**를 누를 때 바뀝니다. 모아치기는 기본적으로 **0.040초 이내**에 입력한 글쇠를 하나의 조합으로 판단하고 단어나 문장으로 변환합니다. 실제 결과는 사용하는 약어 목록에 따라 달라집니다.

## 3. 잠시 끄고 켜기

프로그램을 실행하면 약어 기능이 **켜진 상태(ON)**로 시작합니다. **Scroll Lock 또는 F9**를 누르면 켜고 끌 수 있습니다.

| 상태 | 동작 | Scroll Lock 표시등 |
|---|---|---|
| ON | 약어를 사용할 수 있습니다. | 켜짐 |
| OFF | 입력한 글자가 그대로 입력됩니다. | 꺼짐 |

전환하면 `Open Abbrev = On` 또는 `Open Abbrev = Off`라는 안내가 약 0.8초 동안 나타납니다. 약어와 같은 글자를 그대로 입력해야 할 때는 잠시 OFF로 전환하십시오. 표시등이 없는 키보드에서도 F9를 사용할 수 있습니다.

## 4. 약어 추가하거나 바꾸기

약어 폴더에는 다음 두 파일이 있습니다. **Excel 등의 표 편집 프로그램으로 열어 수정**할 수 있습니다.

- `sequence.csv`: 이어치기 약어 목록
- `chord.csv`: 모아치기 약어 목록

두 파일 모두 왼쪽 열(`keys`)에는 **누를 글쇠**, 오른쪽 열(`output`)에는 **나올 글자**를 적습니다.

**이어치기 예시 (`sequence.csv`)**

```csv
keys,output
func,function
drn,during
```

엑셀에서는
| keys | output |
| func | function |
| drn  | during   |
로 입력합니다.

**모아치기 예시 (`chord.csv`)**

```csv
keys,output
the,the
be,be
```

엑셀에서는
| keys | output |
| the  | the    |
| be   | be     |
로 입력합니다.


약어를 새로 추가하려면 표의 맨 아래에 한 행을 추가하면 됩니다. **같은 약어를 여러 번 적으면 아래쪽에 있는 내용만 적용됩니다.** 모아치기는 글쇠 순서가 달라도 같은 조합으로 취급합니다. 예를 들어 `abc`와 `cba`는 같은 모아치기 약어입니다.

약어에 사용할 수 있는 키워드 글쇠는 영문 소문자 `a`부터 `z`까지와 `;`, `,`, `.`입니다. 이어치기는 대문자와 소문자를 구별합니다.

**참고:** **쉼표가 들어간 필드는 표준 CSV 인용 규칙을 사용합니다.** 따라서 `,`는 큰 따옴표를 사용하여 `","`로 입력해야 합니다. 단, 필드 내부 줄바꿈은 지원하지 않습니다.

## 5. 자판과 입력기에 맞는 목록 고르기

**같은 자판이라도 Windows 입력기와 날개셋 입력기는 서로 다른 약어 목록이 필요할 수 있습니다.** 따라서 사용하는 입력기와 자판 이름에 맞는 폴더를 선택하십시오.

예를 들어 날개셋 입력기의 Colemak에서는 `the`에 해당하는 글쇠를 프로그램이 `fhk`(Colemak의 the를 QWERTY로 친 글자)로 받아들일 수 있습니다. 이 경우 약어 목록에도 `fhk`로 기록해야 합니다. 다른 자판의 약어 목록을 복사했다면 실제로 입력해 보면서 확인하십시오.

## 6. 사용 중 문제가 생기면

- 약어가 바뀌지 않는다면 기능이 ON인지, 올바른 약어 폴더를 선택했는지 확인하십시오.
- 원하지 않는 글자로 바뀐다면 약어 목록에서 해당 항목을 찾아 수정하십시오. 같은 약어가 여러 번 있다면 **맨 아래 항목**을 확인하십시오.
- 다른 키보드 프로그램과 함께 사용하면 입력이 겹칠 수 있습니다. 특히 자체 모아치기 기능이 있는 자판에서는 주의하십시오.
- 프로그램이 필요하지 않을 때는 Scroll Lock 또는 F9로 기능을 끌 수 있습니다.

# Ⅱ. 개발 문서

## 1. 설계 원칙

> 하나의 공통 엔진 + 입력기·언어·자판 배열별 CSV 약어 사전

엔진은 키 수집, 약어 조회, 확장 및 ON/OFF를 담당합니다. 자판별 변환 테이블을 엔진에 넣지 않으며, 입력기별 키 대응은 사전에서 관리합니다.

Windows 입력기는 AutoHotkey가 입력을 처리하기 전에 배열 변환이 적용되는 반면, 날개셋 입력기에서는 AutoHotkey가 QWERTY 기준 입력을 먼저 받는 환경을 전제로 합니다. 따라서 같은 `the`라도 Windows 입력기에서는 `the,the`, 날개셋 Colemak에서는 `fhk,fhk`로 기록할 수 있습니다. 다만 실제 동작은 해당 환경에서 확인해야 합니다.

## 2. 폴더 구조와 사전 선택

```text
open-abbrev/
├── open-abbrev.ahk
├── README.md               # English
├── english/
│   ├── windows-ime/
│   │   ├── qwerty/
│   │   ├── dvorak/
│   │   └── colemak/
│   └── nalgaeset-ime/
│       ├── qwerty/
│       ├── dvorak/
│       └── colemak/
└── korean/
    ├── README.md        # 한국어
    ├── windows-ime/
    └── nalgaeset-ime/
```

위 구조는 목표 구조이며 모든 사전이 동봉되었다는 뜻은 아닙니다. 각 사전 폴더에는 `sequence.csv`, `chord.csv`를 두고, 필요할 때만 `endchars.csv`를 추가합니다. 경로는 `DictionaryDir` 변수로 지정합니다.

## 3. 이어치기·모아치기 사전 규격

| 항목 | 규격 |
|---|---|
| 인코딩 | UTF-8 |
| 파일 | `sequence.csv`, `chord.csv` |
| 헤더 | `keys,output` |
| 주석 | 공백을 제외하고 `#`으로 시작하는 행은 무시 |
| 빈 행 | 무시 |
| 구분자 | 쉼표 |
| `keys` | `a-z`, `;`, `,`, `.` |
| `output` | 빈 값·필드 내부 줄바꿈 지원 안 함. 쉼표·큰따옴표는 표준 CSV 인용 규칙으로 지원 |
| 인라인 주석 | 지원 안 함 |
| 표준 CSV 인용 필드 | 지원 (단, 필드 내부 줄바꿈 제외) |

예를 들어 `",a",example`은 `keys`가 `,a`, `output`이 `example`입니다. 큰따옴표는 `""""`처럼 두 번 써서 이스케이프합니다. Excel에서 저장한 표준 CSV 인용 필드를 읽을 수 있지만, 필드 내부 줄바꿈은 지원하지 않습니다.

**중복 정책은 Last Wins입니다.** 이어치기는 동일한 `keys`가 여러 번 등장하면 마지막 행이 적용됩니다. 모아치기는 `SortKeys(keys)`로 정규화한 서명이 같으면 마지막 행이 적용됩니다. 중복 때문에 초기화를 중단하지 않습니다.

## 4. 종료 문자 설정 (`endchars.csv`)

파일이 없으면 공통 기본 종료 문자 집합을 그대로 사용합니다. 파일이 있으면 `operation,key`의 두 열을 읽어 기본 집합에 추가하거나 제거합니다.

**최종 종료 문자 = (기본 종료 문자 − remove) ∪ add**

날개셋 Colemak 예시:

```csv
operation,key
add,P
add,p
remove,;
remove,:
```

날개셋 Dvorak 예시:

```csv
operation,key
add,Q
add,q
add,W
add,w
add,E
add,e
add,Z
add,z
remove,;
remove,:
remove,'
remove,double-quote
remove,.
remove,comma
```

`comma`는 `,`, `double-quote`는 `"`를 나타내는 예약어입니다. Excel에서 구분자나 인용부호가 잘못 해석되는 일을 피하기 위한 표기입니다. `endchars.csv`는 일반적인 2열 CSV로 취급합니다. 공통 종료 문자에는 공백·Enter·Tab과 지원하는 문장부호가 포함되며, 정확한 기본 목록은 엔진 정의를 기준으로 합니다.

## 5. 이어치기 처리

이어치기는 AutoHotkey v2의 동적 `Hotstring()`으로 등록하며, 대소문자를 구별하고 `SendEvent` 출력 방식을 사용합니다.

```ahk
LoadSequences(path) {
    global SequenceNames
    for entry in ReadDictionary(path) {
        SequenceNames[entry.keys] := true
        Hotstring(":CRSE:" entry.keys, entry.output)
    }
}
```

같은 키가 다시 등록되면 마지막 등록값이 우선합니다. 기존 문자열과 겹치는 약어를 그대로 입력해야 할 때는 일시적으로 OFF로 전환합니다.

## 6. 모아치기 처리

1. 활성 상태에서 지원하는 문자 키 이벤트를 수집합니다.
2. 첫 입력부터 기본 40ms의 입력 창을 사용합니다.
3. 수집한 키를 정렬한 서명으로 `chord.csv`를 조회합니다.
4. 일치하면 `SendEvent`로 확장 문자열을 출력하고, 일치하지 않으면 입력된 키를 재전송합니다.

모아치기는 물리적인 완전 동시 입력 판정이 아니라 짧은 시간 창에 발생한 키 이벤트를 묶는 방식입니다. 중복 조합은 마지막 행이 우선합니다.

## 7. 출력과 상태 전환

모아치기 출력에는 `SendEvent "{Raw}" Chords[signature]`를 사용합니다. `SendText`는 고속 타자 환경에서 관찰된 문제 때문에 사용하지 않습니다. 입력 재전송과 Hotstring 인식이 함께 동작하도록 입력 레벨을 조정한 부분은 Windows에서 확인해야 합니다.

시작 상태는 ON이며 F9·Scroll Lock으로 전환합니다. OFF에서는 `Suspend`를 사용하여 일반 키의 약어 처리를 중단하고, 두 전환 키는 `#SuspendExempt`로 유지합니다. 상태 변경 시 대기 중인 모아치기 버퍼와 타이머를 정리하며, Scroll Lock 표시등을 동기화하고 800ms 동안 툴팁을 표시합니다.

## 8. 구현 및 검증 범위

- 이어치기 대소문자 구분, 중복 시 마지막 행 우선, 모아치기 Shift 우회 동작을 실제 환경에서 검증해야 합니다.
- `endchars.csv`의 add/remove가 날개셋 Colemak·Dvorak에서 예상대로 작동하는지 확인해야 합니다.
- Excel에서 편집·저장한 사전의 인코딩과 구분자 처리를 확인해야 합니다.
- 다른 AutoHotkey 스크립트, 입력기 자체 모아치기, 한·영 전환 및 키 재배치 도구와의 충돌을 시험해야 합니다.

**이 문서는 설계와 사용 방법을 설명합니다. Windows/날개셋 환경에서 모든 동작을 종합 검증했다는 의미는 아닙니다.**

## 9. 프로젝트 범위

목표는 간결한 공통 엔진입니다. 완전한 CSV 파서, 입력기의 자동 판별, 입력기별 변환 테이블, 자판별 전용 엔진은 기본 범위에 포함하지 않습니다.
